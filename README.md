- 최신 내지 교정 PDF: `book/_output/dolphin-said-proof.pdf` (229쪽, 표지 펼침 별도)
- EPUB: `book/_output/dolphin-said-proof.epub`
- 최신 표지 펼침 미리보기: `book/cover/cover-spread-v11-preview.png`
- 표지 배경 원본: `book/images/cover-wrap-panorama-v11.png`

## 다시 조판하기

`book/README.md`의 지침에 따라 확정 원고를 동기화한 뒤 Quarto로 PDF와 EPUB을 다시 생성합니다. 원고 정본은 `drafts/dolphin-said/`이며, `book/src/`는 조판용 생성 사본입니다.

## 공개 범위

원고와 기획·감수 기록은 미출간 저작물입니다. GitHub 저장소는 비공개로 유지하고, 출간 전에는 공개 Pages 배포를 켜지 않는 것을 기본 원칙으로 합니다.
