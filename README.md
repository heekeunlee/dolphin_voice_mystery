## 다시 조판하기

`book/README.md`의 지침에 따라 확정 원고를 동기화한 뒤 Quarto로 PDF와 EPUB을 다시 생성합니다. 원고 정본은 `drafts/dolphin-said/`이며, `book/src/`는 조판용 생성 사본입니다.

## 공개 범위

GitHub 저장소 `heekeunlee/dolphin_voice_mystery`는 사용자의 요청에 따라 공개로 설정했습니다. 미출간 원고와 기획·감수 기록도 공개 저장소에서 열람될 수 있으므로, 이후 추가하는 개인정보·계약정보·비공개 감수 의견은 공개 전에 반드시 검토합니다. 출판 관리 대시보드는 GitHub Pages `/docs`에서 제공합니다.
