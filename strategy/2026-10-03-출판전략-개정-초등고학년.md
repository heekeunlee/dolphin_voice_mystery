## 1. ISBN 부가기호·내용분류·서점 분류

### 1-1. 부가기호 (5자리 = 독자대상 1 + 발행형태 1 + 내용분류 3)

| 자리 | 선택 | 근거 / 비고 |
|---|---|---|
| 독자대상 | **7 아동** | 5~6학년 전용이므로 청소년(4) 선택 근거가 사라짐. 서점·도서관 아동 서가 배치와 일치 [지식] |
| 발행형태(종이) | **3 단행본** 권고 (대안: 4 전집·총서·다권본·시리즈) | 1권 단독 판매·도서관 구입 단위가 낱권이므로 3. 시리즈 표기는 서지의 '총서명'으로 처리 [지식]. 4 사용 시 권별 일관성 필요 |
| 발행형태(전자책) | 전자출판물 코드 — **확인 필요** | 시중 전자책은 `05810`류가 흔하나 현행 코드표를 서지정보유통지원시스템 화면에서 확인 |
| 내용분류 | **810 (한국문학)** — 화면 선택지에 813 소설이 따로 있으면 813 | 국내 소설·동화는 `03810`/`73810` 관행 [지식]. 정확한 선택지는 **확인 필요** |
| **결과(권고)** | **종이책 `73810`**, 전자책 `7?810`(발행형태 확인 후) | |

- 납본·서지 정보의 **이용 대상 '아동'**, 총서명 「곰새코지 바다 지도」, 권차 1 — 서지 등록 시 함께 기재.

### 1-2. 서점 분류 (등록 시 요청 값, 실제 분류는 서점 MD 결정 — **확인 필요**)

| 서점 | 요청 분류 [지식, 경로명은 확인 필요] |
|---|---|
| 교보문고 | 어린이(초등) > 어린이 문학 > 동화 > 고학년 동화(또는 5~6학년) |
| 예스24 | 어린이 > 5-6학년 > 동화/명작/고전 |
| 알라딘 | 어린이 > 동화/명작/고전 > 국내창작동화 (+ 초등 5~6학년 태그) |
| 전자책(리디 등) | 어린이/청소년 > 어린이 동화 |

- 상세페이지 키워드: 고학년 동화, 온책읽기, AI 리터러시, 해양생태, 제주, 해녀, 미스터리. **'성인도 읽는' 류 문구는 쓰지 않음.**

### 1-3. 신규 — 어린이제품 표시(KC) 확인

- 국내 아동 도서 상당수가 뒤표지·판권면에 **KC 표시와 사용연령·제조자·제조국·주의 문구**를 싣는다(어린이제품 안전 특별법상 공급자적합성확인 대상 여부) [지식]. 고학년 동화·POD가 대상인지, **POD에서 '제조자'가 교보(인쇄)인지 에르고스피어인지**, 시험·표시 비용이 얼마인지 **확인 필요** — 국가기술표준원·한국제품안전관리원 문의, 교보 POD에 아동 도서 표지 표시 사례 문의.
- 대상이면 **표지·판권면 조판에 반영해야 하므로 W19(ISBN·바코드 확정) 전**에 결론 필요.

## 2. 판형·조판·삽화·컬러·정가

### 2-1. 판형·조판 (5~6학년 장편 동화 관행 [지식/추정])

| 항목 | 권고 | 비고 |
|---|---|---|
| 판형 | **A5(148×210) 무선** 유지 | 고학년 동화는 150×210 전후~신국판 변형이 많음. A5는 Quarto 스킬 기본값이라 리스크 최소. 교보 A5 옵션 존재 **확인 필요**(기존과 동일) |
| 제본 | **무선** 권고 (날개는 선택) | 날개 = '성인 단행본 인상' 근거가 사라짐. 학교도서관은 내구성(무선 제본 품질·표지 코팅)이 더 중요 |
| 본문 글꼴 | 명조 계열 본문, 장 제목·D-카운트 머리는 고딕 | 아동 도서 표준 |
| 글자 크기 | **12pt 전후(11.5~12.5pt)** | 기존 11pt → 상향 |
| 행간 | **170~180%** | |
| 쪽당 글자 | **약 350~400자** (공백 포함 기준 조판 실측으로 확정) | 기존 450~550자 |
| ASCII 장치 | 고정폭 글꼴, 한 줄 32자 이하(바이블 4-7) — A5 본문 폭에서 12pt 고정폭 32자 **조판 테스트 필요** | 넘치면 고정폭만 10.5pt로 축소 |

### 2-2. 쪽수 추정 [추정 — 조판 후 확정]

| 구성 | 쪽 |
|---|---|
| 앞붙이(표제·판권·차례·작가의 말) | 6~8 |
| 독자 도우미(인물·지도) | 2 |
| 본문 6~7만 자 ÷ 350~400자 | 150~200 |
| 장 도비라·장 시작 홀수쪽 처리(17장) | 17~25 |
| 권말 부록 약 1만 자 | 25~30 |
| **합계** | **약 200~240쪽** (본문 6만 자·장 시작 반쪽 삽화 방식이면 200쪽 안팎) |

- 쪽수 절감 옵션: 장 도비라를 별면 대신 **장 첫 쪽 상단 반쪽 삽화**로 → 약 17쪽 절감. 고학년 동화에서 흔한 방식.

### 2-3. 삽화 수

| 위치 | 수 | 형식 |
|---|---|---|
| 장 도비라(또는 장 첫 쪽 반쪽) | **17** | 흑백 선화(+회색 1톤 이하) |
| 독자 도우미 — 인물 소개·곰새코지 지도 | **2** | 흑백, 지도는 마이크 3곳·지명 고정표와 일치 |
| 본문 컷(절정·구조 장면, 선택) | 0~6 | 14·15장 등 긴 긴장 구간 숨 고르기용 |
| **합계** | **19~25점** | 기존 8~12점 대비 약 2배 |

- 관행 [지식]: 고학년 장편 동화는 대략 10~15쪽마다 삽화 1점. 220쪽 기준 15~20점 → 위 권고와 부합.
- ASCII 스펙트로그램·로그 표는 삽화가 아니라 **조판 요소**로 처리(전자책 리플로 시 이미지 대체 여부는 6단계에서 결정).

### 2-4. 컬러/흑백

- **본문 흑백 유지**(결정 변경 없음, 근거 보강): 고학년 동화는 흑백 본문이 관행이고, 컬러 POD는 원가·정가가 크게 오름(교보 컬러 단가 **확인 필요**). 지도만 컬러로 하고 싶으면 **표지 안쪽(면지)이 아닌 전자책·교사 자료 PDF에서 컬러판 제공**.
- **표지 컬러** 필수 — 고학년 서가에서 표지가 선택을 좌우. 연령 신호(인물 2~3명, 돌고래, 바다)가 분명해야 함.

### 3-2. 학교 도서관·학급 문고

- 학교도서관 구입은 대개 **지역 서점·납품업체 경유** [지식]. 교보 POD 단독 유통이면 납품업체가 조달할 수 있는지가 관건 → **교보 POD의 타 서점·도매 공급 여부(기존 확인 항목 3) 우선순위 상향**.
- 학급 문고·온책읽기는 **학급 인원수(20~30부) 일괄 구매**가 생김 → POD 대량 주문 납기·단가 **확인 필요**.
- **선정 시기** [지식]: 1학기 온책읽기·도서 구입 목록은 **2월(학년 교육과정 협의)**, 2학기는 **7~8월**. 3월 하순 출간이면 첫 기회는 **2학기**(§5).

### 3-4. 학부모 커뮤니티

- 맘카페·초등 독서 커뮤니티는 **카페별 홍보 규칙**(제휴 게시판·운영자 승인) 준수 — 무단 홍보 글 금지.
