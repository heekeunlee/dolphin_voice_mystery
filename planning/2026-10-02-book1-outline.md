# 1권 장별 아웃라인 — 『돌고래가 말했다, 돌려줘』

- 작성: 기획자(PD) / 작성일: 2026-10-02 / 단계: 3단계
- 기준 문서: `planning/2026-10-02-series-bible.md` (인물·세계관·톤·금지 조합 G1~G13)
- 사양: 14장, 장당 4,500~6,000자, 총 7~8만 자. 장 도비라 흑백 삽화 1점/장(삽화 제안 포함)
- 시점: 3인칭 제한. 준(1·2·3·5·6·7·8·11·12·13·14장), 채아(4·9장), 하안(10장)
- 기간: 2033년 6월 24일(1장) ~ 8월 6일(14장)

## 0. 구조 한눈에

| 막 | 장 | 핵심 |
|---|---|---|
| 1막 — 오역의 탄생 | 1~4 | 리더보드 1위 준, "돌려줘" 공개, 마을 분열, 채아와 절교 |
| 2막 전반 — 추적 | 5~7 | 꼼수 라벨 발견(숨김), 불턱·숨비소리, **중간 반전: 문장이 아니라 이름** |
| 2막 후반 — 대가 | 8~11 | 소장의 거절, 채아의 원본, 하안의 '번역', 태풍 밤의 정정문 |
| 3막 — 듣기 | 12~14 | 위치 추정, **절정: 엔진을 끄자**, 정직한 결말과 새 휘슬 |

- **중간 반전(7장)**: "돌려줘"가 나온 휘슬 W-07은 먹이를 먹을 때도, 쉴 때도, 배가 없을 때도 같은 모양으로 반복된다 → 문장이 아니라 이름. 그리고 그 이름은 말젯이가 사라진 날부터 세 배로 늘었다.
- **2차 반전(5장→8장)**: 오역의 첫 원인은 준 자신의 라벨봇. 준은 숨기다가 8장에서 고백한다.
- **절정(13장)**: 소장의 '반달 소리 틀기' 지시를 거부하고, 모든 배의 엔진을 끄게 해 들리지 않던 소리를 듣는다. 구조는 부분 성공.
- **정직한 결말(14장)**: 공식 정정. 그러나 새끼 꼬리엔 낚싯줄이 남았고, 관광선 선장은 과태료를 물고, 준은 대회에서 상을 못 받고, '누구의 이름인지'는 여전히 모른다. 할머니의 마지막 물질 날, 할머니가 처음으로 투의 숨비소리를 이름으로 부른다. 그날 밤, 이름 사전에 없는 휘슬이 들어온다.

## 1장. 리더보드 1위 (약 5,000자)
- **시점**: 준 / 6월 24일
- **장면**
  1. 새벽 다섯 시 반. 준의 방. 리더보드 1위 화면. '라벨봇'이 밤새 붙인 라벨 2,140개. 할머니가 테왁을 챙겨 올해 마지막 시즌 첫 물질을 나간다. 준은 배웅하지 않는다.
  2. 분교 6학년 교실(7명). 채아가 '돌핀로그' 새 영상 조회수를 자랑. 하안은 엄마 통역하느라 지각. 담임이 '전국 청소년 AI 챌린지'(8월 6일 마감) 공고. 채아: "너 돌고래 실제로 본 적은 있냐?" 준: "데이터로는 1만 2천 번."
  3. 저녁. 엄마는 야간 근무 후 자고 있다. 할머니가 혼잣말처럼 "말젯이가 요새 안 뵌다." 준은 이어폰을 낀다.
  4. 밤. 물마루연구소 생중계 "바당이, 첫 문장을 말하다". 화면에 세 글자: **돌려줘.** 아래 작은 글씨 '근거 녹음 조각 #A-3318 / 라벨: 어미-새끼 분리 위협 / 라벨러: jun_0101'.
- **감정**: 지루한 자신감 → 무관심 → 짜릿함(내 이름이 저기 있다)
- **단서/정보 공개**: 라벨봇이 "관광선 위치 앱 + 휘슬 폭주"로 라벨을 자동으로 붙인다는 설명을 준이 '꿀팁'처럼 자랑스럽게 생각(C1) / 말젯이 안 보임(C2) / 할머니 마지막 시즌(C3) / 라벨에 라벨러 이름이 남는다(C4)
- **장 끝 훅**: "그 라벨을 붙인 건 준이 아니었다. 준이 잠든 사이 준의 프로그램이 붙인 것이었다. 그리고 지금, 온 나라가 그걸 보고 있었다."
- **교육 포인트**: [AI] 개념: 라벨=소리 조각에 붙이는 이름표 → 예시: 준의 하루 300개 → 실무적 의미: (보류, 5장에서 회수)
- **독자 참여**: 「라벨링 해 보기」 — 녹음 조각 세 개의 상황 설명(예: '배 엔진 소리 + 짧은 휘슬 여러 번')과 라벨 보기 5개. 정답 없음, 14장에서 "당신은 무엇을 근거로 골랐나?"로 회수
- **삽화**: 방파제 위 노트북 화면 불빛, 멀리 테왁 하나
- **셀프체크**: G1~G13 위반 없음 — 좌초로 시작 안 함(G3), 주인공 바다 공포 없음·물질 장면은 원경(G9), 고래 비유 없음(G6) ✅

## 2장. 돌려줘 (약 5,500자)
- **시점**: 준 / 6월 25~26일
- **장면**
  1. 아침, 마을에 방송 차량. 차명훈 소장 기자회견: "돌고래가 우리에게 처음 건넨 말입니다." 돌고래 넥타이.
  2. 다섯 개의 해석: 해녀회장 김복자("배 때문에 바다를 돌려달라는 거여"), 어촌계장 강덕수("관광객 끊기면 마을 끝"), 돌고래쉼표 윤나래("자유를 돌려줘"), 오션톡 썸네일("인류에게 보내는 바다의 경고?"), 채아의 영상("우리 배한테 화났대요?" — 조회수 100만). 관광 예약 취소 문자가 양 선장 휴대폰에 쏟아진다.
  3. 준은 들떠서 대회 출품작 제목을 정한다: 「내 라벨이 만든 첫 문장」. 할머니: "곰새기(돌고래)가 무사 사람 말을 해?" 준: "할머닌 데이터를 몰라서 그래요."
  4. 밤. 중계 다시보기에서 화면 구석 '확신도 31%'를 본다. 넘긴다. 서지원 박사의 문자: "준 학생, 라벨을 어떤 방식으로 붙였는지 설명해 줄 수 있어요? 내일 연구소로 와요."
- **감정**: 흥분·우쭐함 → 작은 불안
- **단서**: 확신도 31%(C5) / 소장의 "국민이 감동" 화법 첫 등장(C6) / 채아가 영상을 '잘 나오게' 자르는 습관 언급(C7)
- **장 끝 훅**: 서 박사의 문자. "어떤 방식으로."
- **교육 포인트**: [미디어] 개념: 사람은 믿고 싶은 대로 읽는다(확증편향 — 이미 가진 생각에 맞는 정보만 골라 믿는 버릇) → 예시: 다섯 해석 → 실무적 의미: 채아가 올린 영상 댓글을 보며 처음 멈칫함
- **독자 참여**: 「같은 문장, 다섯 얼굴」 표 — 해석 다섯 개와 '이 해석으로 이득 보는 사람' 연결하기
- **삽화**: 휴대폰 화면 다섯 개가 겹친 콜라주, 가운데 '돌려줘'
- **셀프체크**: 메시지를 '경고'로 읽는 건 등장인물(오션톡)의 오독으로만 제시, 작품은 부정(G1) ✅ / 실명 기관 없음(G7) ✅

## 3장. 바당이의 네 단계 (약 5,500자)
- **시점**: 준 / 6월 27일
- **장면**
  1. 오삼촌의 트럭으로 연구소에. 옛 수협 창고. 벽 지도에 수중 마이크 1·2·3번 삼각형(C8). 오삼촌: "엔진 끄면 다 들려. 사람도 그렇고."(C9)
  2. 서 박사의 화이트보드: 듣기 → 나누기 → 짝짓기 → 문장 만들기. 연구소 원칙 세 줄(재생 금지 C10 / 모르는 건 모른다 / 라벨에 이름). "네 번째 단계는 내가 반대했어."
  3. "31%는 '맞을 확률'이 아니야. 패턴이 얼마나 비슷하냐는 거지." 서 박사가 묻는다. "하룻밤에 2천 개는 어떻게?" 준: "빨리 들었어요." (거짓말)
  4. 차 소장 등장. 다음 주 방송 특집, 그다음 주 연구비 재선정 심사. "준 학생, '시민 과학 소년'으로 출연해 줄래요?" 서울 캠프가 눈앞에 그려진다.
- **감정**: 호기심 → 찔림 → 유혹
- **단서**: 세 마이크 배치(C8) / 엔진 대사(C9) / 재생 금지 원칙(C10) / 번역 레이어는 소장이 밀어붙임(C11)
- **장 끝 훅**: 복도에서 서 박사가 낮게 말한다. "이 문장, 학회엔 못 내. 그런데 소장님은 방송에 낸대. 준아, 네 라벨 한 번만 다시 봐 줄래?"
- **교육 포인트**: [AI] 개념: AI 파이프라인(단계별로 일하는 순서)과 확신도 → 예시: 31% → 실무적 의미: 준이 '숫자의 뜻'을 처음 질문함
- **독자 참여**: 「바당이 로그」 고정폭 상자 — 라벨 기록 20줄 중 '새벽 3:02:04, 3:02:08, 3:02:12…' 4초 간격 줄을 독자가 먼저 찾게(사람이 새벽 3시에 4초마다?)
- **삽화**: 화이트보드의 네 칸 다이어그램
- **셀프체크**: 바당이 감정·의인화 없음(G12 확장) / 음모·안드로이드 없음(G11) ✅

## 4장. 잘라 낸 장면 (약 5,000자)
- **시점**: 채아 / 6월 29일~7월 1일
- **장면**
  1. 묶여 있는 '모살개 3호'. 식탁 위 배 대출 고지서. 아빠는 말이 없다.
  2. 포구 시위. 돌고래쉼표 피켓, 해녀들과 선장들의 말다툼("배가 작업장까지 들어오잖여!"/"우리도 먹고살아야지!"). 채아는 찍고, 아빠 쪽에 유리하게 편집한다.
  3. 구멍가게 앞에서 준과 맞닥뜨림. "너네 연구소 때문에 우리 집 망해." "데이터가 그렇게 나온 거야." "데이터? 그거 네가 붙인 거잖아." 절교.
  4. 밤, 편집. 6월 14일 원본을 넘기다 새끼 꼬리에 뭔가 검은 게 끌리는 컷을 지나친다. 그 컷엔 아빠 배가 너무 가깝게 찍혀 있다. 채아는 늘 그런 컷을 버렸다.
- **감정**: 억울함 → 분노 → (무의식적) 찜찜함
- **단서**: 6월 14일 원본, 새끼 꼬리의 검은 것(C12) / 아빠 배 접근 거리 위반(C13) / 채아의 '빼는 버릇'(C7 회수 시작)
- **장 끝 훅**: "채아는 그 파일을 늘 그랬듯 휴지통으로 끌어다 놓았다. 휴지통 비우기는 누르지 않았다."
- **교육 포인트**: [미디어] 개념: 맥락 잘라내기(앞뒤를 자르면 같은 장면도 다른 뜻이 된다) → 예시: 시위 영상 편집 → 실무적 의미: 채아가 '안 올린 장면'을 의식하기 시작
- **독자 참여**: 「채아의 편집 타임라인」 — 원본 10컷 목록과 실제 올린 4컷. 빠진 6컷 중 의미가 뒤집히는 컷 찾기
- **삽화**: 편집 화면의 타임라인, 휴지통 아이콘
- **셀프체크**: 이해관계자(선장)를 악당으로 그리지 않음 / 돌고래 시점 없음(G12) ✅

## 5장. 라벨봇 (약 5,500자)
- **시점**: 준 / 7월 2~3일
- **장면**
  1. 준이 자기 라벨을 뽑아 본다. '분리 위협' 라벨의 82%가 라벨봇 작품. 규칙: "관광선이 마이크 100m 안 + 휘슬 1분에 5회 이상 → 분리 위협." 배 위치를 '돌고래 상황'의 대신으로 쓴 것.
  2. 휘슬 묶음표에서 W-07이 유난히 많다. 배가 없을 때도. 준은 '이상함' 메모만 남긴다. 표 맨 아래 '미분류 #0' 묶음(C14).
  3. 대회 마감, 방송 출연. 준은 스크립트 파일 이름을 'test_old'로 바꾼다. 서 박사에게 "제 라벨은 문제없어요"라고 답장. 책상에 0과 1을 두드린다.
  4. 노트북에서 W-07을 틀어 놓고 있는데 할머니가 들어온다. "그 소리 안다. 반달이 소리여. 말젯이 없어진 뒤로 저 소리만 혀."
- **감정**: 충격 → 공포(들킬까) → 자기합리화 → 당황(할머니가 안다?)
- **단서**: 라벨봇 규칙 공개(C1 회수) / W-07 과다(C15) / 미분류 #0(C14) / 할머니의 개체 식별 능력(C16)
- **장 끝 훅**: 할머니의 대사. 준은 처음으로 할머니에게 묻는다. "그걸… 어떻게 알아요?"
- **교육 포인트**: [AI] 개념: 대리 변수의 함정(재기 어려운 것 대신 재기 쉬운 걸 쓰면 엉뚱한 걸 배운다), "쓰레기가 들어가면 쓰레기가 나온다" → 예시: 배 위치 = 분리 위협 → 실무적 의미: 준의 숨김(나쁜 선택을 먼저 보여 준다)
- **독자 참여**: 「라벨봇 버그 찾기」 — 의사코드 5줄
  ```
  만약 관광선_거리 < 100m 이고
     휘슬_횟수(1분) >= 5 이면
        라벨 = "어미-새끼 분리 위협"
  아니면
        라벨 = "이동"
  ```
  → "이 규칙이 틀리는 상황 세 가지를 적어 보자"
- **삽화**: 'test_old'로 이름이 바뀌는 파일 아이콘
- **셀프체크**: 주인공 결함을 외부 악당 없이 제시 / 바다·물질 공포 없음(G9) ✅

## 6장. 불턱 (약 6,000자)
- **시점**: 준 / 7월 5일
- **장면**

## 13장. 엔진을 꺼 주세요 — **절정** (약 6,000자)
