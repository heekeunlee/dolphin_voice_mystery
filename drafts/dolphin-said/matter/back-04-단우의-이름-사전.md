# 단우의 이름 사전

단우가 노트 맨 뒷장의 '모름' 칸을 옮겨 만든 파일이에요.

한 돌고래에게 이름이 여러 개 있어요. 연구소 번호, 할머니 별명, 휘슬 번호.

연구소에 낸 공개본이라, 붙인 사람 이름은 가렸어요.

```
이름 사전 | 반달
연구소 번호 MR-047
할머니 별명 반달
휘슬 번호   W-07?
메모        지느러미 뒤쪽이 반달 모양
            W-07이 누구 이름인지는 모름
```

```
이름 사전 | 말젯이
연구소 번호 미등록
할머니 별명 말젯이 (제주어로 셋째)
휘슬 번호   모름
메모        7/31 큰여 바깥, 반달 옆
```

```
이름 사전 | 불쑥이
연구소 번호 MR-012
할머니 별명 불쑥이
휘슬 번호   모름
메모        지느러미 끝이 뜯김
            카메라 앞에 불쑥 떠오름
```

```
이름 사전 | #A-3318
휘슬 번호   W-07
바당이 문장 돌려줘
메모        오역. 맞아 보인 건 우연.
```

```
이름 사전 | 새 줄
휘슬 번호   W-31, W-32, W-33
연구소 번호 없음
할머니 별명 없음
붙인 사람   시민 라벨러 A
이유        모름
메모        F-D-D-U는 생중계 날 밤에도
오늘 밤     측량선 시험 운항
```
