**알아 둘 것**

- 물속 소리는 1초에 약 1,500m를 가요.
- 그래서 0.01초 늦으면 15m 더 먼 거예요.
- 한 칸은 가로세로 100m예요.

| | 가 | 나 | 다 | 라 | 마 | 바 | 사 |
|---|---|---|---|---|---|---|---|
| 1 | 방 | | | | | | 큰 |
| 2 | | | | | | | |
| 3 | | | | | | | |
| 4 | | | | 등 | | | |
| 5 | | | | [ ] | [ ] | [ ] | |
| 6 | | | | [◎] | [▲] | [▲] | |
| 7 | | | | [▲] | [▲] | [▲] | |

방 = 방파제 마이크 / 큰 = 큰여 마이크 / 등 = 등대 마이크

[ ] 노란 칠 / ▲ 그물먹는여 바위 / ◎ 투가 '물 색 다르다'고 한 곳

**1단계** [정답] 시간차를 거리 차이로 바꾸세요.

```

큰여 마이크: 0.21초 늦게
방파제 마이크: 0.28초 늦게
```

### 10. 세 마이크 퍼즐

- 이 격자는 퍼즐을 위해 줄인 그림이에요. 책 앞 「소리코지 바다 지도」와 거리·축척이 같지 않습니다.

**정답**

- 1단계: 0.21초 × 1,500m = 315m, 0.28초 × 1,500m = 420m.
- 2단계: ○는 마5, 마6, 마7. 나머지 여섯 칸은 ×.
- 3단계: 마6. 마5는 바위 칸이 아니고, 마7은 ◎과 꼭짓점만 닿습니다.

| 칸 | 큰여−등대 | 방파제−등대 | 판정 |
|---|---|---|---|
| 라5 | 400 | 400 | × |
| 마5 | 310 | 430 | ○ |
| 바5 | 190 | 420 | × |
| 라6 | 380 | 380 | × |
| 마6 | 320 | 420 | ○ |
| 바6 | 230 | 430 | × |
| 라7 | 370 | 370 | × |
| 마7 | 310 | 400 | ○ |
| 바7 | 250 | 420 | × |

**검산 과정 (python으로 확인)**

- 격자: 7×7칸, 한 칸 100m. 칸 한가운데를 그 칸의 자리로 씁니다.
- 좌표: 가1 한가운데를 (50m, 50m)로 두고 오른쪽·아래로 늘립니다.
- 마이크: 방파제 가1 (50, 50), 큰여 사1 (650, 50), 등대 라4 (350, 350).
- 정답 칸 마6 한가운데: (450, 550).
- 마6에서 거리: 등대 223.6m, 큰여 538.5m, 방파제 640.3m.
- 시간차 = 거리 차이 ÷ 속도(1,500m/s).
- 큰여: (538.5 − 223.6) ÷ 1,500 = 0.2099초 → 0.21초.
- 방파제: (640.3 − 223.6) ÷ 1,500 = 0.2778초 → 0.28초.
- 활동지의 시간차는 0.01초 단위로 반올림한 값입니다.
- 거리 표는 칸 한가운데 사이의 곧은 거리를 10m 단위로 반올림했습니다.
- 49칸 전체를 같은 기준(30m 이내)으로 검사하면 마5·마6·마7만 남습니다.
- 그래서 노란 칸 밖에 숨은 답은 없습니다.
- ○인 칸의 오차는 20m 이하, ×인 칸의 오차는 55m 이상입니다.
- 허용 범위를 20~50m 사이 어디로 잡아도 같은 세 칸이 나옵니다.
- 단서만 쓰면 라7·마6 두 칸이 남습니다.
- 시간차와 단서를 함께 써야 마6 하나로 정해집니다.
- 세 칸 모두 등대가 가장 가깝습니다. 그래서 '등대에 제일 먼저'와 맞습니다.
