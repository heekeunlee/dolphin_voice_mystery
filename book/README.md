# 조판 — 『곰새코지 돌고래 목소리 사건』

조판 소스. **원고의 정본은 `drafts/dolphin-said/chNN-final.md`와 `drafts/dolphin-said/matter/`** 이다.
확정 원고는 17개 편집 단위이며, `tools/sync.py`가 인접한 내용을 묶어 출판본 9장으로 만든다.
`book/src/`와 `book/index.qmd`는 생성 사본이므로 직접 고치지 말 것.

## 다시 만들기

```sh
export PATH="$HOME/opt/quarto-1.10.18/bin:$HOME/Library/TinyTeX/bin/universal-darwin:$PATH"
cd book
python3 tools/sync.py        # 확정 원고 → src/ (HTML 주석 제거, 부속물 인쇄 부분만)
quarto render                # _output/dolphin-said-proof.pdf, .epub
```

도구: Quarto 1.10.18(`~/opt`, 휴대용 설치), TinyTeX(`~/Library/TinyTeX`), poppler(Homebrew).

## 현재 결과 (장 통합 교정쇄, 2026-10-08)

- 17개 원고 단위를 9개 장으로 묶은 A5 PDF(229쪽)와 EPUB을 생성했다. 차례와 쪽수는 통합본 기준으로 갱신했다.
- 기존 17개 단위의 제목은 본문 안 소제목으로 남기고, 삽화도 버리지 않았다. 새 장 도비라 9점과 해당 이야기 위치의 무제 삽화 8점으로 모두 보존했다.
- 뒷부분의 장 번호 참조도 새 장 번호로 고쳤다. 날짜 흐름과 장 경계의 연속성을 확인했다.
- 레드팀 1차(reviews/dolphin-said/2026-10-05-조판-교정쇄1-레드팀.md) 반영: 홑따옴표 짝(‘ ’ 247쌍), é 대체 글꼴, 화면 상자 쪽 넘김 금지, [정답] 대괄호, 날짜 줄 스타일, 머리글=장 제목, 쪽 끝 제목 방지, ◇ 쪽 끝 방지, 소리 모양(U-D-F) 줄 끝 분리 금지, 판권 마지막 짝수 쪽, 부록 문단 스타일, 차례 장 번호 고정 폭.
- LaTeX 넘침: 0.5pt·1pt 각 1건(눈에 안 띄는 수준).
- (교정쇄 2차 기준) 이후 『시간 고양이』 판면으로 바꾸며 344쪽이 됨. 책등 추정 21mm(344쪽, 장당 0.12mm) — 교보 템플릿 값으로 교체 필요.

## 남은 조판 과제

- 활동지(탐구 노트) 쪽: 쓸 칸·괘선·격자를 디자인 쪽으로 다시 짜기(표 대신 그림 쪽 권장). 소리 그림은 선 그림 파일로.
- 쪽 아래 끝이 1~2줄 짧은 쪽(raggedbottom) — 그림이 들어간 뒤 최종 흐름에서 다시 본다.
- 장 삽화 17점과 지도 그림이 들어왔다. 통합본에서는 9점은 새 장 도비라에, 나머지 8점은 해당 이야기의 원래 위치에 무제 삽화로 배치했다.
- 표지와 판권 값은 아직 미완료.
- 교정쇄 PDF: `_output/dolphin-said-proof.pdf`; 작업 폴더 최상위에도 `수정된-원고.pdf`가 있다.

## 『시간 고양이』 판면 실측 (2026-10-05)

알라딘 미리보기 이미지(1권, 500×731px = 143×209mm)에서 잰 값. 오차 약 ±0.3mm.
판형 143×209mm, 236쪽 / 본문 폭 87mm, 양끝 맞춤 / 쪽당 19줄 / 줄 간격 8.0mm / 글자 높이 3.72mm(약 12~12.5pt 추정).
우리 책 렌더 기준: 19줄, 글자 높이 약 3.71mm, 줄 간격 8.0mm, 폭 87mm. 판형은 기존 출판 결정에 따라 A5(148×210mm)를 유지하고, 좌우 여백은 안쪽 34mm·바깥쪽 27mm, 위 24mm·아래 37.5mm로 명시한다.
미리보기는 이미지이므로 원본 글꼴 파일명까지 확인할 수 없다. 본문은 같은 명조 계열의 나눔명조로 통일하며, 메시지·앱 알림·쪽지·메모 등은 현재의 전용 글꼴 스타일을 유지한다.
