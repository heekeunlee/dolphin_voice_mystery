1. **말젯이의 '오늘'을 한 번 보이기** (1권 질문 닫기 + 에필로그 불안 오독 막기)
   - 현재: 탁 박사가 종이컵 두 개를 들고 언덕길을 내려왔다. 하나를 단우에게 내밀었다. / "넌 코코아. 연료는 어른 거야."
   - 수정안: 위 **보강 1** 그대로. 최소안(대사 한 쌍): 탁 박사가 종이컵 두 개를 들고 언덕길을 내려왔다. 단우가 먼저 물었다. / "박사님, 말젯이는요?" / "어제 조사선이 봤어. 반달 옆에 딱 붙어 있더래. 상처는 지켜봐야 알고." / 탁 박사가 컵 하나를 내밀었다. "넌 코코아. 연료는 어른 거야."
   - (이것 없이 A는 마지막 장에서 말젯이 소식을 못 듣고 덮으며, "W-07은 없었다."를 '말젯이네가 사라졌다'로 읽을 수 있다)

2. **"투 올라왔다"의 무게에 손잡이 하나** (개념 ②)
   - 현재: 목소리가 얼마나 컸는지, 방파제의 하안이 돌을 던지다 말고 돌아보았다. 할머니는 그대로 끈만 감았다. / "단우!" 투가…
   - 수정안: 위 **보강 2** 그대로(하안 "삼춘! 방금 우리 엄마 불렀어요?" / 할머니 "투 올라왔다 했다. 왜." / "…아니요!" / 물수제비 여섯 번).
   - (서술로 '처음'을 짚지 않고, 투의 아들이 놀라 외치는 것으로 사건화. 할머니 대답은 인정이면서 설명이 아님)

3. **에필로그 '새 줄' 블록 메모 두 줄의 이어 읽기 오독 막기** (개념 ⑧)
   - 현재:
     ```
     메모        W-33은 생중계 날 밤에도
     같은 시각   측량선 시험 운항
     ```
   - 문제: 두 줄이 한 문장처럼 이어져 "W-33은 생중계 날 밤에도 같은 시각(에) 측량선 시험 운항"으로 읽힘 → A가 '생중계 날 밤에도 측량선이 있었다'로 오독(실제로는 오늘 밤만). 또 W-31~33 중 어느 것이 F-D-D-U인지 A가 셈해야 함.
   - 수정안:
     ```
     메모        W-33, 생중계 날 밤에도 들림
     오늘 밤     측량선 시험 운항 21:30~22:30
     ```
     그리고 블록 바로 앞 문장을 "단우는 헤드폰을 목에 걸고, 나온 순서대로 번호를 붙여 이름 사전 맨 아래에 새 줄을 만들었다."로.
   - (메모 줄을 '들림'으로 끝내 문장을 닫고, 라벨을 '오늘 밤'으로 바꿔 시각의 주인을 분명히 함. 시각 범위는 공지 블록 숫자의 반복이라 새 숫자 아님. 블록 32자 이하 확인 필요. 아웃라인 '같은 시각' 라벨을 지키려면 `같은 시각   측량선 시험 운항(오늘 밤)`도 가능)

4. **U-F를 장소가 아니라 '새끼 소리일지 모른다던 소리'로 부르기** (개념 ⑦ — '새끼 소리도 아닌')
   - 현재: W-07은 없었다. 소등굴 입구에서 잡히던 U-F도 아니었다.
   - 수정안: W-07은 없었다. 오삼촌이 새끼 소리 아니냐던 U-F도 아니었다.
   - (A가 기억하는 U-F의 꼬리표는 15장 오삼촌 대사다. 장소 이름으로는 되살아나지 않음. 보강 1과 함께면 '말젯이네는 잘 있고, 이건 또 다른 누군가'로 읽혀 2권 궁금증이 정확해짐)

5. **listen.py와 마이크의 주어 어긋남 풀기** (에필로그 첫머리 오독)
   - 현재: 옆 창에서는 listen.py가 돌고 있었다. 저녁에 오삼촌이 방파제 끝 쇠고리에 다시 매달아 준 휴대용 마이크였다.
   - 문제: 두 번째 문장의 생략된 주어가 'listen.py'로 읽혀 A·C가 "listen.py가 마이크야?"로 멈춤.
   - 수정안: 옆 창에서는 listen.py가 방파제 마이크 소리를 듣고 있었다. 저녁에 오삼촌이 방파제 끝 쇠고리에 다시 매달아 준 휴대용 마이크였다.

### 권장 (작가 판단)
1. 작은 표지 셋(각 몇 자):
   - 채아 "원본 고마워요, 그 댓글도요?" → "'원본 고마워요', 그 댓글도요?" (16장 댓글 인용임을 따옴표로)
   - 투 "그때 오늘 끝나면 꼭이랬지?" → "그때 '오늘 끝나면 꼭요' 했지?"
   - 단우 "그날 이 바위 앞에서 받은 거예요." → "그날 이 바위 앞에서 녹음한 거예요."
   - (선택) 투 "이게… 나야?" 뒤에 "내 소리, 나는 못 듣는 줄 알았어." 반 줄 — 6장 "나는 한 번도 못 들었어."의 메아리로 ③을 O로 올림.
2. '이름 사전'(블록 머리) / `이름지도`(저장 이름) / '이름 지도'(탁 박사 프로젝트) 정리: 파일 소개 문장을 "노트 맨 뒷장의 '모름' 칸을 옮겨 온 파일, 이름은 '이름지도'였다."로 하면 단우가 프로젝트 이름을 자기 파일에 붙였다는 게 보이고 마지막 저장 개그(`이름지도` 그대로)도 단단해짐. 블록 머리 '이름 사전'(바이블 7-4)은 그대로 둬도 됨.
3. 마지막 두 문단이 연달아 '단우는'으로 시작("단우는 그 글자를…" / "단우는 헤드폰을 다시 썼다."). 앞 문단 주어를 빼 "그 글자를 하나씩 지우고, 원래 이름 `이름지도` 그대로 저장했다."로 하면 마지막 문장이 더 또렷이 선다(마지막 문장 자체는 바꾸지 말 것).

### 고치지 않아도 되는 것 (확인)
- 엄마 등장 "너네 엄마도 와?" / "…몰랐어." / 웃음소리가 멎음 / 문지방을 넘지 않음 — 사연 설명 0이 맞다.
- 감귤 장면 대사 넷("새벽 세 시에 깨는 버릇은…", "손으로 해야 귀에 남지.", "축하한 거다. 진짜로.", "웃는 얼굴이야, 그거.") — 세월 대사 0, 친척 암시 0 유지.
- "그거 미성년자도 돼요?" / "이름은 가리고." / "엄마한테 먼저 물어볼게요." / "그래야지."
- 정임 "맞혔냐? 테레비 나오는 거냐?" / "아니요! 그냥 들은 거예요!" / "에이, 아깝다." — 6·13장 반복 개그의 완성.
- 물수제비 "그럼 영상 보고 정정해." — 1권 키워드를 아이 놀이로.
- "녹음은?" / "오늘은 안 해요. 그냥 들을래요." / 할머니가 더 묻지 않음.
- "투 올라왔다." 앞뒤의 할머니 손(끈 감기 계속, 고개 그대로) — 설명 넣지 말 것(보강 2는 하안의 놀람으로만).
- 투 "끝이 평평하네. 삼춘 거는 끝에 내려가는데." / "나도. 한 번 더 들을래."
- 숨비소리 공백 → U-F-F-D → "할머니." / "삼춘." → "웃는데, 단우는 목 안쪽이 뜨거워졌다."
- 수건 → "…밥은?" → "…아직." → 반걸음 뒤. **어떤 해설도 붙이지 말 것.**
- "해라." / "대신 이건 내 거다. 쓸 때마다 물어봐라." / "…네. 쓸 때마다요."
- 은퇴 잔치 "물때 봐야 알주." / "회요!" / "고기요!"
- 메모 `오역. 맞아 보인 건 우연.` — 물음표를 지우고 고쳐 쓰는 손동작으로 '정정'을 마무리.
- +1을 '펼쳐' F-D-D-U가 나오는 장면 — 1권 마지막 소름.
- `붙인 사람 고단우` — 단우 개인 파일이라 독자 반응상 문제 없음(16장 '이름은 가리고'와 충돌로 읽는 A 없음. 오히려 '자기 이름을 걸고 모름을 쓴다'로 읽힘). 출간 정책 판단은 심사 몫.
- `이름지도_최종_진짜최종` → "…버그." → 원래 이름으로 저장 → "단우는 헤드폰을 다시 썼다."

## 7. 정합 메모 (독자 반응 관점)

- **W-07의 부재**: 에필로그 마이크는 방파제(14·15장 W-07·U-F는 그물먹는여·소등굴·등대 쪽). A는 장소 차이를 따지지 않으므로, 'W-07 없음'을 '말젯이네 없음'으로 읽지 않게 하는 장치는 보강 1(말젯이 근황)뿐이다.
- **+1의 두 번**: 14장 `12:06 미분류-모름 +1`(그 뒤 U-F로 드러남)과 15장 `23:59:02 미분류-모름 +1`(이 장에서 F-D-D-U). B 일부는 "+1은 U-F 아니었어?"로 헷갈릴 수 있으나, 이 장이 등대 마이크 블록 원문(23:58:30 W-07 / 23:59:02)을 그대로 다시 보여 주므로 '생중계 날 밤의 그 +1'로 특정됨. 정합 O.
- **측량선 시간**: 공지 21:30~22:30, 새 소리 21:41 — 물질 시간(새벽)과 겹치지 않아 16장 마을 약속('물질하는 동안 관광선은 멀리서')과 정합 O. 16장 이해도 메모의 '31일 겹침' 우려 해소.
- **투 말투**: 단우에게 반말("그 오늘, 한참 지났어." "나도. 한 번 더 들을래."), 할머니에게 해요체("네, 삼춘!") — 6장 규칙 O.
- **동의 범위**: 단우가 맞히는 사람은 정임뿐(13장에서 소리 호명 허락), 김복자 0, 투는 할머니가 부름 — 아웃라인 E-1 O.
- **15장 v2와의 연결**: 이 장의 "소등굴 입구에서 잡히던 U-F"는 15장 v2 블록(13:12:40)을 전제로 함. 15장 v2가 확정되면 고칠 것 4의 오삼촌 대사 원문("저거, 새끼 소리 아니냐?")이 그대로 남아 있는지 함께 확인.
