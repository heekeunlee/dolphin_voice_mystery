| 방송 쾌속정 | 현장 진행자·카메라 | O | 14장 "그물먹는여 건너편" 위치 그대로. 이장 장면에서만 다시 등장 |
| 스튜디오(태블릿) | 진행자 | O | "스튜디오 진행자가 귀를 짚었다" |

- **총평: A는 따라간다(△+~O).** 단우가 한 배에 고정되어 있고, 다른 배는 '쌍안경 → 맨눈 → 무전'으로만 들어오는 설계가 좋다. 잠수사가 "소리코지 3호 옆에서 고개를 내밀었다"도 위치를 잃지 않게 해 줌.
- 걸림 두 곳: ① "양 선장, 갑니다." 화자 ② **"뱃전 몇 칸 거리"** — 거리를 못 그려서, 뒤의 "채아야, 받아!"(바람막이 던지기)에서 A가 "배가 다른데 어떻게 던져?"로 멈춤. 앞에서 '던지면 닿는 거리'를 깔아 두면 던지기가 자연스러워짐. → 고칠 것 5
- C(4학년)는 배 넷 + 갯바위 + 방파제 + 스튜디오가 한꺼번에 나와 △. 할머니가 탄 배만 잡으면 줄거리는 따라감.

## 5. 대화 비율을 올릴 위치 2곳 (25.5% → 28% 이상)

필요량: 서술을 그대로 두고 대사만 더하면 약 **130~170자**. 아래 두 곳(약 90~110자) + 고칠 것 4(혼잣말 약 20자) + 고칠 것 5(무전 표지 정리)로 28~29% 예상. 두 곳 모두 '~었다' 4연속을 함께 끊는다.

### 보강 1 — 방파제 승선 (오삼촌의 한마디: 리듬 + 개념 ①)
- 위치: "채아네 배가 방파제에 뱃전을 댔다. 할머니가 난간을 쥐었다." 뒤
- 수정안: 채아네 배가 방파제에 뱃전을 댔다. 할머니가 난간을 쥐었다.
  "어르신 배 타는 거, 나 처음 본다." 오삼촌이 쌍안경 너머로 중얼거렸다.
  쌍안경 속에서도 그 손이 떨리는 게 보였다.
- (오삼촌은 동네 사람이라 '처음'이라는 말에 무게가 실림 → A가 "진짜 큰일이구나"를 말함. 쌍안경은 단우에게 건넸으므로 오삼촌은 "맨눈으로 방파제를 보며"로 써도 됨. 약 20자 대사)

### 보강 2 — 악플 밤 (단우의 추락 한 박자 + 엄마 귀가)
- 위치 ①: "하지만 오려 낸 영상 속 아이디는 아무도 가려 줄 수 없었다." 앞
  - 수정안(추가): "…이름은 가려 줬는데." 단우가 혼잣말을 했다.
- 위치 ②: "현관문 여는 소리가 났다. 간호사 가방을 멘 엄마가 방문 앞에 섰다."
  - 수정안: "단우야." 현관에서 엄마 목소리가 났다. 간호사 가방을 멘 엄마가 방문 앞에 섰다.
- (①은 11장 '시민 라벨러 A' 약속이 지켜졌다는 걸 단우 입으로 확인 → A가 "연구소는 지켰는데 영상이 문제"를 구분. ②는 '~었다' 4연속을 끊고, 엄마가 화면보다 먼저 '단우'를 부른다는 작은 순서도 생김. 합계 약 20자 대사. 더 필요하면 ① 뒤에 "거짓말한 초딩." 단우가 첫 줄을 소리 없이 따라 읽었다. 같은 반복은 피할 것 — 셋 중 둘만)

## 6. 판정

- **판정: 조건부 통과 (고칠 것 5개 + 보강 1·2 반영 후 심사로).** 할머니 승선·"거기까진 나도 모른다"·전문가 구조·엄마의 밤은 이미 확정 수준이다. 고칠 것은 모두 반 줄~한 줄이며, 반영 시 분량은 약 3,400~3,450자(상한 안), 대화 28~29%.
- 개념 테스트 요약: ① 할머니 승선이 큰일인 이유 **△+**(→ 고칠 것 1로 O) / ② "모른다"의 무게 **△+**('처음'과 전문가 인계는 O, 정정문과의 짝은 B 몫) / ③ 구조 주체 **O** / ④ 새끼 상태 **△+**(→ 고칠 것 2로 O) / ⑤ 휴대폰 엎기 **O** / ⑥ 9,308개 뺀 출품 **△+**(제목 오독 → 고칠 것 4) / ⑦ 장 끝 +1 **△**(A 대부분 '말젯이 대답'으로 읽음 — 7절)

### 반드시 고칠 것 (우선순위)

1. **스크루 회상에 '물벗'을 되살리기** (개념 ①, 할머니 본인 부상 오독 차단)
   - 현재: 불턱에서 돌아온 밤에 들은 말이 떠올랐다. / '배 밑에서 도는 스크루에 다리를 크게 다쳤다.'
   - 수정안: 불턱에서 돌아온 밤, 할머니가 들려준 물벗 이야기가 떠올랐다. / '배 밑에서 도는 스크루에 다리를 크게 다쳤다.'
   - (6장 원문 인용은 그대로 두고 앞 문장에 '물벗'만. 12장 "배 스크루에 다쳤다던 할머니의 물벗 이야기"와 같은 표지. 약 8자 증가. 보강 1과 함께 넣으면 '~었다' 4연속도 해소)

2. **W-07 '1분에 두 번'에 기준점 붙이기** (개념 ④, 장 첫머리 '늦어짐=나쁨'과 거꾸로 읽힘 방지)
   - 현재: 줄이 내려오는 간격이 넓어지더니, 1분에 두 번으로 줄었다.
   - 수정안: 줄이 내려오는 간격이 넓어지더니, 1분에 두 번으로 줄었다. 태풍 밤에는 1분에 열한 번 울던 소리였다.
   - (11장 원문 숫자 재사용 — 새 숫자 0. 돌고래 내면 서술 없이 '덜 급하게 부른다'를 A가 스스로 만듦(G12 유지). 7장 "6월 13일부터 세 배"를 쓰고 싶으면 "6월 13일부터 세 배로 울던 W-07이었다." 약 20자)

3. **"한 시 반 전이다."를 만조와 잇기** (C33, 시계 하나가 닫히는 순간)
   - 현재: "한 시 반 전이다." / 할머니가 혼잣말처럼 말했다.
   - 수정안: "물 다 차기 전이다. 한 시 반 전." / 할머니가 혼잣말처럼 말했다.
   - (13장 탁 박사 풀이 "물이 제일 많이 차는 때"를 할머니 말투로 되받음. '만조'를 그대로 쓰려면 "만조 전이다. 한 시 반 전." 제주어 새 형태 0. 약 8자, 대사)

4. **새 제목 「맞은 것과 안 것」의 '안' 오독 막기** (개념 ⑥, C34 회수의 핵심)
   - 현재: 단우는 새 제목을 치고, 파일을 하나씩 끌어다 놓았다.
   - 수정안: 단우는 새 제목을 쳤다. "찍어서 맞은 거랑, 들어서 안 거." 혼잣말을 하며, 파일을 하나씩 끌어다 놓았다.
   - (8장 "날마다 같은 번호만 찍는 애도, 가끔은 동그라미를 받는다"와 단우의 귀(3장 "네 귀로")를 한 줄로 되받음. 교훈 문장이 아니라 제목 읽기. '안 것 = 알게 된 것'이 소리로 들려 A가 "맞은 거랑 틀린 거"로 읽지 않음. 약 20자, 대사)

5. **배 위치 표지 두 곳 정리** (3절, 인물 추적 + 바람막이 던지기)
   - (가) 현재: "양 선장, 갑니다." → 수정안: "소리코지 3호, 갑니다." 채아 아빠 목소리였다.
   - (나) 현재: 물마루 1호와는 뱃전 몇 칸 거리라, 할머니 얼굴이 맨눈으로 보였다. → 수정안: 물마루 1호와는 공을 던지면 닿을 거리라, 할머니 얼굴이 맨눈으로 보였다.
   - ((가)는 13장 무전 호출 형식 "물마루 1호, 여기 소리코지 3호."와 같은 꼴 — '양 선장'을 굳이 쓰려면 "채아 아빠, 양 선장 목소리였다." (나)는 뒤의 "채아야, 받아!"를 미리 깔아 던지기가 자연스러워짐. 합계 약 10자 증가)

### 권장 (작가 판단)
1. "채아 아빠는 키에서 손을 떼지 않았고" → "채아 아빠는 배 키를 놓지 않았고" ('키' 오독 완화).
2. "새로 고칠 때마다 댓글이 늘었다." → "화면을 새로 고칠 때마다 댓글이 늘었다."
3. "11분이 넘어서야 한 줄이 겨우 붙었다." → "12시 11분이 넘어서야 한 줄이 겨우 붙었다." (11분 동안으로 읽힘 방지)
4. "물때 봐야 알주." 회상 뒤에 "그때는 대답을 비켜 갔었다." 한 줄 — '비켜 감 → 처음 모른다'의 대비가 A에게도 보임(개념 ② 가). 서술 1문장이라 대화 비율엔 약간 손해.
5. "꼭대기가… 6월 초 모양이랑 비슷해." — 7절 정합 메모 참고.

### 고치지 않아도 되는 것 (확인)
- 무전 정적 → 탁 박사가 무전기를 내려놓음 → "나다. 그물먹는여 바위는 내가 안다." — 설득 없는 승선, 이 장의 심장.
- 테왁이 물살에 끌려가다 멈추는 표시 방법, "입구 왼쪽에 소 등짝 같은 바위, 그 밑이 좁아."(설명 0 유지).
- 문지혜 지시 대사 3단(줄 → 숨 → 그물), '푸우.' 한 줄, 초록색 덩어리(6월 12일 회수).
- 채아 "말젯이, 엄마 옆에 붙었어." + '이거'라고만 했던 9장 회수.
- 이장 물보라 / "현장? 화면이 왜 이렇죠?" / "다 젖었네." — 이장 의도 단정 0.
- 엄마 장면 전체("봤어. 병원에서." / 엎기 / 베란다 한 문장 / "엄마도 아직." / 그릇 두 개).
- 탁 박사 `오늘 연료는 몇 잔째인지 셀 수 없음.` — 긴장이 풀린 밤에 딱 맞는 웃음.
- 봇·감지기 마지막 줄 2줄 블록 + "둘 다 단우가 친 줄이었다." (A는 △+, B는 O. 해석 문장 더 넣지 말 것)

## 7. 정합 메모 (독자 반응 관점)

- **W-07 '꼭대기 모양 변화'(C23)가 확정본에 심기지 않음**: 아웃라인 C23은 "6/13부터 세 배 + 꼭대기·폭 변화(7장 심기)"인데, 7장 확정본에는 **"하루 평균 세 배"(횟수)만** 있고 꼭대기·폭 변화 문장은 없다(ch07 212·268행). 그래서 "꼭대기가… 6월 초 모양이랑 비슷해."를 A는 **근거 없는 말**로 읽거나, 7장 "꼭대기만 보고 어떻게 알아요?"(지느러미 꼭대기)와 섞어 "지느러미 꼭대기?"로 오독한다. 선택지: (가) 15장을 횟수로 바꿈 — "울리는 게… 6월 초랑 비슷해." / "비슷한 거고." (나) 13장 v2에 모양 변화 한 줄을 심음. (가)가 고칠 것 2와 겹쳐 가장 싸다.
- **장 끝 `미분류-모름 +1`의 읽힘**: 14장에서 '미분류-모름' = 굴 속 새끼 쪽 소리로 학습됐고, 장 끝 블록이 'W-07 → 30초 뒤 +1'로 14장 구조와 같아 A 대부분이 **'말젯이의 대답'(따뜻한 끝)**으로 읽는다. 아웃라인 의도('아직 모르는 새 소리' — 17장 회수, 2권 씨앗)를 지키려면 17장 회수 때 "말젯이 소리와는 다른 모양" 같은 구분이 필요하고, 15장에서 미리 구분하고 싶다면 블록에 모양 하나를 붙이는 방법(`미분류-모름 F-D +1` 등, 14장 U-F와 다르게)이 있다. 이 장에서는 '따뜻하게 읽혀도 손해가 없는' 클리프라 그대로 두고 17장 쪽에서 맞추는 것을 권함.
- 13장 v2: 할머니 "태풍 뒤엔 물이 소등굴로 감아 들어."가 바뀌면 15장 "물이 소등굴로 감아 든다 했지."도 같이 맞출 것. 수의사 "12시 40분에 도착해요"는 15장 "12시 40분이라고 했어"·"15분이나 일찍"과 정합 O.
- 14장 v2에서 이해도 고칠 것 5("속도 올릴게요")를 넣으면 15장 "15분이나 일찍"이 씨앗-회수로 이어짐 — 넣지 않으면 A는 '그냥 일찍 왔다'로 읽고 지나감(문제는 없음).
