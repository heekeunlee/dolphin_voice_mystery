## 총평 한 줄
**"안 틀어요 → 프로펠러 → 엔진까지 → 정적 → 모름 → 두 선이 겹친다"의 계단이 분명하고, 어른이 책임지고 아이가 귀를 빌려주는 구도가 A에게 정확히 보인다.** 탁 박사의 거절은 이유("엄마는 바로 저기 있어요")와 책임("제가 책임질게요")이 짧게 붙어 A가 그대로 따라 말하고, 오삼촌의 "엔진 끄면 다 들려" 회수와 진행자의 "지금… 아무 소리도 안 들립니다"는 A가 소리 내어 웃거나 소름이 돋는 자리다. 걸리는 곳은 넷이다. ① **장 끝 "줄과 줄 사이"를 A가 화면의 줄 간격으로 읽고**, 간격이 벌어지는 게 왜 나쁜지 모른다(클리프가 반만 작동). ② **'미분류-모름' 소리가 왜 새끼를 찾는 열쇠인지** — 반달 휘슬과 함께 울린다는 단서도, 봇이라면 이름을 붙여 버렸을 거라는 대비도 이 장 안에 없다. ③ **프로펠러를 세웠는데 엔진이 왜 아직 도는지** C는 물론 A 일부도 그림이 안 그려진다. ④ **3장 농담이 이번엔 정답**이라는 단우의 깨달음 한 박자가 빠졌다(아웃라인 "단우는 이번엔 그 말을 알아듣는다"). 여기에 **절정의 정적이 두 줄 만에 꼬르륵으로 넘어가** 숨 멎는 순간이 짧다. 고칠 것과 보강을 합치면 약 300~400자로, 분량 미달도 함께 해소된다.

## 3. 절정의 감정 곡선 — 긴장 → 정적 → 발견, 실제로 오르나

| 구간 | A의 몸 반응 | 판단 |
|---|---|---|
| 소장 통화·거절 | **오른다.** 머그잔 쥔 손가락 마디가 하얗다 → "안 틀어요." → 소장의 "그 학생이라도 한마디만" → "그건 더 안 돼요." A가 "박사님 멋있다"를 말하는 지점. 단우가 숨을 참고 있었다는 걸 아는 문장이 독자의 숨과 겹침 | 좋음 |
| 12시 정각, 쾌속정 돌진 | **오른다.** 화면이 반으로 갈리고 하얀 물살 → 오삼촌 무전 낚아채기. 속도감 좋음 | 좋음 |
| 프로펠러 → 엔진 | **유지.** 6장 회상과 메모가 들어와 잠시 '설명 모드'. 짧아서 크게 처지지 않음 | 그대로(고칠 것 3은 대사로 넣어 속도 유지) |
| 엔진 끄기 릴레이 | **최고조 직전까지 오른다.** 물마루 1호 → 탁 박사 무전 → 채아 "아빠, 빨리!" → 방송 배 버팀 → "그것도 제가 책임져요." → "뚝 멎었다." A가 통쾌함을 느끼는 첫 번째 정점 | 좋음 |
| **정적** | **짧다.** "바다에 파도 소리만 남았다." 한 줄 뒤 바로 진행자 속삭임 → 스튜디오 → 꼬르륵. 진행자 속삭임까지는 정적을 키우지만, 꼬르륵 농담이 **단우가 아직 아무것도 못 들은 상태에서** 들어와 숨 멎는 시간이 두세 문장밖에 안 된다. A는 웃고 넘어가며 "들렸어?"의 초조함을 거의 겪지 않는다 | **보강 1** |
| 감지기 블록 → 발견 | **오른다, 그러나 짧게.** W-07 `?` → 패턴, 그리고 "처음 보는 줄". 블록이 시각적으로 강해 A가 몸을 기울임. 다만 **W-07이 또렷해지는 순간 단우의 반응이 0**이라 '드디어 들렸다'의 해방감이 블록에만 맡겨짐 | **보강 2** |
| 딱총새우 → "모르는 거예요" → 귀로 듣기 | **오른다.** 5장 자기 말 회수가 강함. "지금은 시간이 그때보다 더 없었다."가 좋다 | 좋음(고칠 것 2로 이유 보강) |
| 채아 무전 → 두 선 겹침 → "안 움직여요" | **두 번째 정점.** "단우야, 우리 쪽에도 떴어!"에서 A가 소리 지름. "안 움직여요"의 떨림에서 통쾌가 곧바로 불안으로 바뀌는 전환이 정확 | 좋음 |
| 수의사 → 할머니 → 블록 | **다시 초조.** 구조가 시작됐는데 시계가 짧다 | 좋음(고칠 것 1·5) |

- **통쾌한가**: **엔진 끄기(어른 쪽 통쾌)는 강하고, 감지기 '모름'(아이 쪽 통쾌)은 중간.** 엔진 릴레이는 '규칙을 지키라는 사람이 이긴다'는 단순한 통쾌라 A가 바로 받는다. 반면 '모름'의 통쾌는 "봇이었으면 지워졌을 소리를 단우 프로그램은 남겨 뒀다"를 알아야 터지는데, 그 대비가 이 장에 없다(개념 ③). 고칠 것 2를 넣으면 두 통쾌가 나란히 선다.
- **유머가 절정을 깨는가**: 진행자 속삭임·"현장, 들리십니까?"는 정적을 오히려 키움(좋음). **꼬르륵 + 연료**는 위치만 문제. 정적 2~3문장(보강 1) 뒤로 밀리면 긴장 → 웃음 → 블록 재긴장의 리듬이 산다. 삭제할 필요는 없음.

## 5. 장 끝 클리프

- 현재: 할머니 "만조까지 한 시간 이십 분." → 블록 3줄(12:07:30 / 12:08:20 / 12:09:40) → "줄과 줄 사이가 조금씩 벌어지고 있었다." → 헤드폰 누른 손에 힘.
- **시계(만조)**: A **O.** 13장 "만조가 한 시 반"을 기억하고, '1시간 20분 = 다 왔다'는 숫자가 크게 들림. 15장을 펴게 하는 힘은 충분.
- **간격(두 번째 시계)**: A **X~△.** 두 군데서 걸린다.
  1. **"줄과 줄 사이"를 화면의 행 간격으로 읽는다.** 블록은 줄 간격이 똑같이 보이므로 A는 "안 벌어졌는데?"로 멈춘다. 시각 숫자를 빼서 50초 → 80초를 계산하는 5학년은 드물다.
  2. **벌어지는 게 왜 나쁜지 모른다.** "점점 덜 운다 = 힘이 빠진다(또는 멀어진다)"를 A가 혼자 만들지 못해, 마지막 문장의 긴장은 할머니 시계 하나에만 실린다.
- 블록 시각 어긋남: 본문은 "12시 8분, 소리가 다시 울렸다"까지 간 뒤 "줄이 **또 하나** 내려왔다"라고 하는데, 블록은 **세 줄**이고 첫 줄이 그보다 이른 **12:07:30**이다. 꼼꼼한 A·B는 "12시 7분 반이면 아까 거잖아?"에서 반 박자 걸림. '새로 내려온 줄'이 아니라 '모름 줄만 모아 본 화면'으로 바꾸면 해결. → **고칠 것 1**
- 15장 욕구: **강함.** "구조팀이 제때 오나", "소리 주인이 진짜 새끼인가", "만조 전에 꺼낼 수 있나" 세 가지를 A가 들고 넘어간다.

## 7. 판정

- **판정: 조건부 통과 (고칠 것 5개 + 보강 1·2 반영 후 심사로).** 거절 장면(개념 ①)과 엔진 릴레이, 어른/아이 역할 구분은 이미 완성 수준이다. 고칠 것은 모두 반 줄~두 줄 추가·교체이며, 반영하면 분량 미달(1,998자)과 대화 비율(28.7%)도 함께 올라간다(고칠 것 3·5가 대사).
- 개념 테스트 요약: ① 녹음 안 튼 이유 **O** / ② 엔진까지 끈 이유 **△+**(→ 고칠 것 3으로 O) / ③ '미분류-모름'이 위치를 찾게 한 방법·봇과의 대비 **△**(위치 절차는 O, 새끼와의 연결·봇 대비가 △~X → 고칠 것 2로 △+~O) / ④ 3장 "엔진 끄면 다 들려"의 의미 **△+**(→ 고칠 것 4로 O)

   - 수정안: 단우는 '미분류-모름' 줄만 모아 보았다. / (블록 그대로) / 50초, 그다음은 80초. 소리와 소리 사이가 조금씩 벌어지고 있었다. 점점 드물게 울린다는 뜻이었다.

### 권장 (작가 판단)
1. 꼬르륵·연료 농담을 보강 1 뒤로 — 위치는 그대로 두되 정적 문장이 먼저 쌓이면 충분(3절).
2. 두 선 교차: "물마루 1호에서 뻗은 선"을 B가 "마이크 하나로 방향을 어떻게 알아?"로 물을 수 있음. A는 지도 그림으로 받아들이므로 이 장에선 그대로. 필요하면 "소리가 온 쪽으로" 세 글자 정도.
3. "그 약속이 바로 지금이었다." — '약속'이 반 박자 걸리면 "그 말이 바로 지금이었다."

### 고치지 않아도 되는 것 (확인)
- 탁 박사 거절 대사 전체, "그건 더 안 돼요." — 미성년 보호가 설교 없이 행동으로 전달됨.
- 진행자 속삭임 / "현장, 들리십니까?" / 소장이 진행자 팔을 잡는 행동 — 소장 비악당화 성공.
- 메모 #5 급식실 비유, 6장 회상 "여긴 배가 지나가서 다 덮였어요."
- 감지기 블록 7줄(`=` 막대가 줄어드는 시각 효과) — A가 가장 오래 들여다볼 곳.
- 딱총새우 회수와 "지금은 시간이 그때보다 더 없었다."
- 채아 무전 → "소등굴 입구예요." → "안 움직여요."의 속도.

### 13장 v2·15장 정합 메모 (독자 반응 관점)
- **답장 문안 불일치(반드시 맞출 것)**: 13장 v1 첫 블록은 `[01:12] 탁 박사: 봤어. 판단은 내가 해.`인데, 14장은 "'잘 보냈어. 판단은 내가 해.'"를 글자 그대로 회수한다고 쓰여 있다. 13장 v2에서 "잘 보냈어."로 바꾸기로 했다면 문제없음. 바꾸지 않는다면 14장을 "'봤어. 판단은 내가 해.'"로 맞출 것 — A는 회수 문장을 앞 장과 대조해 읽는 습관이 있어 한 글자 차이도 "어? 아까는 봤어였는데"로 걸린다.
- 13장 수의사 "12시 40분에 도착해요"와 14장 "지금 가요"의 관계는 고칠 것 5로 정리. 15장 '15분 일찍'과도 이어짐.
- 13장 오삼촌 "엔진까지 끄라는 말은 없어." → 14장 스스로 열쇠를 돌림: 고칠 것 4 권장 혼잣말로 대비를 살리면 오삼촌 인물 곡선도 닫힘.
